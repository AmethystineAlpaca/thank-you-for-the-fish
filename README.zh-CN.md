## 人在工位，心在海湾

桌面角落，一艘小木船晃晃悠悠。

水面泛光，倒影散开，鱼线和浮标跟着水波轻轻摇。

你不用一直管它。

鱼咬钩时，浮标下沉，鱼竿提起，小鱼带着水花蹦出海面。名字、重量和收获信息会直接显示出来，然后自动进入鱼篓。

就算你当时没看到，也不会错过。

你可以随手把小船拖到喜欢的位置，也可以拖动右下角的 **◢** 调整大小。

支持：

- **60%–150% 缩放**
- 默认窗口置顶
- 跨桌面显示
- 自动记住位置和大小

船下方的鱼讯条会从暖红逐渐变成浅绿，小三角在里面来回游走。

它不会告诉你“还有 37 秒咬钩”。

只会给你一种若有若无的暗示：

**是不是快来了？**

## 100 种海洋生物，把工位钓成水族馆

目前共有 **100 种鱼类和其他海洋生物**，分布在 5 组图鉴里。

从浅海里熟悉的小家伙，到深海里怎么看都不像应该出现在办公桌上的奇怪生物，全都被做成了软乎乎的玩具感造型。

没钓到之前，它们藏在剪影和问号后面。

第一次钓起来，图鉴里的格子才会真正亮起来。

名字、外观、介绍、长度、重量和收藏估值也会随之解锁。

最让人惦记的，往往永远是还差的那一只。

端杯水回来，桌面上可能就多了一条新鱼。

也可能还是熟悉的老朋友。

不过颜色好像有点不对。

**“再等一条就关。”**

这句话通常不太可信。

## 同一种鱼，还能开出不同款

钓到一种鱼，只是开始。

每种生物都可能出现 **4 种性状**：

**100 种生物 × 4 种性状 = 400 种收藏组合。**

再加上随机体长、重量和收藏估值，同一种鱼也不一定长得一样。

- **普通款**  
  原生配色。简单、耐看，也是你最先认识它的样子。

- **异色款**  
  同一种鱼换了一套新的颜色。熟悉，但明显哪里不一样。

- **荧光款**  
  鱼身带上发光色彩和霓虹轮廓，光效缓缓呼吸，同时尽量保留原本的眼睛、花纹和身体细节。

- **炫彩款**  
  流动渐变、珠光、彩色高光和闪片一起上场。没什么必要，但非常好看。

特殊配色不是把所有鱼统一染成同一种颜色。

它会尽量沿着每种鱼原本的色彩关系变化：

冷色系会偏向冰蓝、淡紫和玫粉，暖色系则更常出现杏金、珊瑚粉和浅紫。

**小鱼可以重样，惊喜不必重样。**

稀有物种、特殊性状，再加上一个特别夸张的体型，这一竿就很值得截图。

打开鱼获详情后，它们还会继续动。

鱼尾摆动，鱼鳍轻扇，触手摇晃，特殊光效也会随身体一起变化。

你本来只是想查一下这条鱼值多少贝壳。

然后开始盯着它看。

## 鱼可以慢慢钓，鱼篓一定要漂亮

每条鱼获都会记录：

- 名字
- 性状
- 重量
- 体长
- 收藏估值

鱼篓还会统计：

- 累计鱼获
- 已发现物种
- 特殊鱼获
- 贝壳总值

你可以按名字搜索，也可以根据性状筛选，或者按钓获时间、价值和重量排序。

**想看闪的？**  
直接筛选异色、荧光和炫彩。

**想找某一条？**  
输入名字就行，不用在鱼群里翻。

**想比大小？**  
按重量排序，看看谁才是真正的大块头。

**等不及了？**  
点击 **「试钓一下」**，可以直接预览一次完整钓鱼效果。

试钓不会加入正式收藏，也不会影响正常的咬钩计时。

贝壳只是收藏估值。

没有商店，没有出售，也没有交易系统。

这里最值钱的东西，大概还是工作间隙里偷来的那几分钟。

## 马上开钓

### 直接下载

当前发布版本适用于 **Apple Silicon（M 系列芯片）Mac**。

1. 打开 [最新版本](https://github.com/AmethystineAlpaca/thank-you-for-the-fish/releases/latest)。

2. 下载：

   `thank-you-for-the-fish-macos-arm64.zip`

3. 解压后，将 **Thank You for the Fish.app** 拖进「应用程序」。

4. 打开应用。

桌面上出现小船，顶部菜单栏出现 **Thank You for the Fish**，就已经开钓了。

### macOS 不让打开？

当前发布包尚未经过 **Developer ID 签名与公证**。

如果 macOS 阻止第一次打开，请先确认安装包来自本仓库的官方 Release 页面，再参考 Apple 官方说明：

[打开来自身份不明开发者的 Mac App](https://support.apple.com/zh-cn/guide/mac-help/mh40616/mac)

### 常用按钮

| 想做什么 | 去哪里点 |
| --- | --- |
| 查看鱼获 | 小船下方「鱼篓」，或菜单栏 **Thank You for the Fish → 打开鱼篓** |
| 查看图鉴 | 鱼篓左侧「海洋图鉴」 |
| 调整咬钩节奏 | 「垂钓设置」，可在 **1–120 分钟**范围内设置随机间隔 |
| 暂停 / 继续 | 小船下方 **Ⅱ / ▶** |
| 缩放小船 | 拖动右下角 **◢**，支持 **60%–150%**；双击恢复默认大小 |
| 找不到小船 | 菜单栏 **Thank You for the Fish → 显示小船** |
| 退出 | 菜单栏 **退出 Thank You for the Fish**，或鱼篓左下角退出按钮 |

收藏会自动保存在本机。

退出应用不会清空鱼获，但：

- 退出期间不会累计离线鱼获
- 重新启动后会重新开始等待
- 电脑从休眠恢复时，最多补收一条鱼

请避免同时运行开发版和打包版，以免读取同一份本地数据。

> 生物造型、稀有度、尺寸、重量和贝壳估值均为游戏化设计，并非科学数据。

## 从源码运行

需要：

- **macOS**
- **Node.js 22.12.0 或更高版本**
- **npm**

```sh
git clone https://github.com/AmethystineAlpaca/thank-you-for-the-fish.git
cd thank-you-for-the-fish
npm ci
npm start
```

首次安装需要联网下载依赖和 Electron。

安装完成后，钓鱼、图鉴和收藏都可以离线运行。

之后从源码启动，只需要：

```sh
npm start
```

如果 Electron 提示安装不完整：

```sh
node node_modules/electron/install.js
npm start
```

### 打包 Apple Silicon 应用

```sh
npm run package
```

生成位置：

```text
dist/Thank You for the Fish-darwin-arm64/Thank You for the Fish.app
```

项目根目录中的：

```text
双击启动小憩海湾.command
```

可以直接启动本地打包版本。

修改源码后，需要重新执行打包命令，双击入口才会加载最新版本。

Intel Mac 打包方式以及其他开发说明见：

[开发说明](docs/DEVELOPMENT.md)
